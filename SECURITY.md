# Security policy

AfterCare handles sensitive health-related data, so we take security reports seriously.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Email **contact@after-care.eu** with the subject line "Security". Include:

- what you found and which part of the project it affects (mobile app code, storage, networking)
- steps to reproduce, or a proof of concept
- the impact as you understand it

Please do not access, change or delete data that is not yours, and do not test against real users. Give us a reasonable time to fix the problem before you publish details. We will acknowledge your report and keep you updated.

## Scope

The mobile app in this repository, including local storage, how it derives keys and encrypts the STI type, and how it talks to the server.
